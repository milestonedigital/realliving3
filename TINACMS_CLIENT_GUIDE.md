# TinaCMS - Guia para Seu Cliente

## 🎯 Como Usar o CMS para Editar o Site

### Passo 1: Acessar o Admin
1. Abra seu navegador
2. Vá para: **`https://realliving3.netlify.app/admin`**
3. Você verá a interface do TinaCMS

### Passo 2: Fazer Login
1. Clique em **"Login with TinaCMS"**
2. Faça login com sua conta TinaCMS (a mesma que foi configurada)
3. Autorize o acesso se pedido

### Passo 3: Editar Conteúdo

#### 📝 Editar Blog Posts
1. No menu esquerdo, clique em **"Blog Posts"**
2. Selecione um post para editar
3. Modifique o título, descrição, data, autor, imagem
4. Escreva o conteúdo no editor
5. Clique em **"Save"**

#### 📄 Editar Páginas
1. No menu esquerdo, clique em **"Pages"**
2. Selecione uma página (Home, About, Contact, etc.)
3. Edite o conteúdo
4. Clique em **"Save"**

#### 🛠️ Editar Serviços
1. No menu esquerdo, clique em **"Services"**
2. Selecione um serviço
3. Modifique nome, descrição, ícone, preço
4. Clique em **"Save"**

### Passo 4: Adicionar Novo Conteúdo
1. Clique em **"+ New"** na seção desejada
2. Preencha os campos
3. Clique em **"Save"**

### Passo 5: Upload de Imagens
1. Clique no campo de imagem
2. Selecione uma imagem do seu computador
3. A imagem será enviada automaticamente

---

## 💾 Salvando Mudanças

**Importante:** Quando você clica em **"Save"**, as mudanças são:
- ✅ Salvas no GitHub automaticamente
- ✅ Publicadas no site em poucos minutos
- ✅ Versionadas (você pode voltar a versões anteriores)

---

## 🔍 Visualizar Mudanças

Após salvar:
1. Espere 2-3 minutos para o site fazer deploy
2. Recarregue o site principal
3. Suas mudanças estarão ao vivo!

## ⚠️ Dicas Importantes

### ✅ Faça
- Sempre clique em **"Save"** após editar
- Use títulos descritivos
- Adicione imagens de alta qualidade
- Revise o conteúdo antes de salvar

### ❌ Não Faça
- Não feche a página sem salvar
- Não delete conteúdo importante sem backup
- Não modifique a estrutura do site

---

## 🆘 Problemas Comuns

### "Página em branco ao acessar /admin"
- Recarregue a página (F5)
- Limpe o cache do navegador (Ctrl+Shift+Delete)
- Tente em outro navegador

### "Não consigo fazer login"
- Verifique sua conexão com internet
- Certifique-se de estar usando a conta correta
- Tente fazer logout e login novamente

### "Mudanças não aparecem no site"
- Espere 2-3 minutos para o deploy
- Recarregue o site principal
- Verifique se clicou em "Save"

### "Erro ao salvar"
- Verifique se todos os campos obrigatórios estão preenchidos
- Tente novamente
- Contate o suporte se persistir
